Getting started with Amidst the Clouds

Amidst the Clouds is listed as a platformer game. Start by checking the opening screen for the objective and any instructions for your device.

What to expect

Amidst the Clouds is a really creative game where you need to get to the exit using arrow keys to move, and jumping on the special white "smoke" will make you float up or down, and the airflows will push you! Press space to start the game.

Tips for your first session

Use the first obstacles to learn the timing. If you miss the same jump twice, change where you start it before changing your whole route.
